# AI CRM Platform

Plataforma CRM impulsada por Inteligencia Artificial enfocada en la gestión de clientes, automatización de seguimientos y administración visual de pipelines de ventas mediante tableros Kanban.

El proyecto está diseñado bajo una arquitectura moderna SaaS utilizando Next.js, NestJS y PostgreSQL, incorporando autenticación RBAC, dashboards analíticos y automatización inteligente mediante IA.

---

## ✨ Características Principales

### 👥 Gestión de Leads y Clientes
- Administración de clientes y prospectos
- Gestión de estados y prioridades
- Seguimiento comercial
- Notas y actividad por cliente

### 📋 Pipeline Kanban
- Visualización de leads mediante tableros
- Drag & Drop de estados
- Organización visual del flujo de ventas
- Gestión dinámica de pipelines

### 🧠 Inteligencia Artificial Integrada
- Generación automática de seguimientos
- Creación inteligente de tareas
- Resúmenes automáticos de actividad
- Automatización de workflows

### 🔐 Autenticación y RBAC
- JWT Authentication
- Roles y permisos dinámicos
- Gestión multiusuario
- Seguridad basada en roles

### 📊 Dashboard Analítico
- Métricas de ventas
- Leads activos
- Conversión de clientes
- Actividad reciente
